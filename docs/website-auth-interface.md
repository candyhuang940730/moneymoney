# 地下網站登入頁介面約定

本階段只有 `GET /site/` 會回傳登入首頁。以下路徑留給下一階段實作；目前沒有登入、忘記密碼或資料庫邏輯。

| 操作 | 預定路徑 | 預定資料 |
| --- | --- | --- |
| 登入表單 | `POST /site/login` | `username`、`password` |
| 忘記密碼入口 | `GET /site/forgot-password` | 無 |

登入失敗訊息可放在表單的 `.form-feedback` 區域。日後加入真正的登入處理時，需一併設計 CSRF 保護、Session 與伺服器端驗證；預定挑戰漏洞的具體行為則在該階段確認。

最外層導覽頁與任務中心已提供導覽及任務簡報。環境重置按鈕、資料庫中的受邀帳號、FLAG 檢驗器與進度紀錄，均留待後續階段實作。
